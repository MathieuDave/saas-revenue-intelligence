# SaaS Revenue Intelligence

A full-stack SaaS Revenue Intelligence application built to help Revenue, Customer Success, and Sales teams understand revenue performance, identify retention risks, uncover expansion opportunities, and prioritize customer actions.

## Project Architecture

- Frontend: React + TypeScript
- Backend: Node.js + Express + TypeScript
- Data Platform: Databricks
- Analytics: Databricks SQL / Unity Catalog
- AI Copilot: Databricks Genie
- Version Control: Git + GitHub

## Application

The application will include:

- Executive Overview
- Customer Risk Intelligence
- Expansion Intelligence
- Customer 360
- AI Revenue Intelligence Copilot
